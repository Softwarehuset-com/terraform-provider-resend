# resend_domain (Data Source)

Reads an existing domain.

## Example Usage

```terraform
# Look up an existing domain by name (or use `id` instead — exactly one).
data "resend_domain" "inbound" {
  name = "mail.appcompany.com"
}

# Wire its records into your DNS provider without owning the domain in this
# stack. Example with the Cloudflare provider:
#
# resource "cloudflare_record" "mx" {
#   for_each = {
#     for rec in data.resend_domain.inbound.records :
#     "${rec.record}-${rec.type}-${replace(rec.name, "*", "wild")}" => rec
#     if rec.type == "MX"
#   }
#
#   zone_id  = var.cloudflare_zone_id
#   type     = each.value.type
#   name     = each.value.name
#   value    = each.value.value
#   priority = each.value.priority
#   ttl      = 1 # Auto
# }
```

### Optional

- `id` (String) Resend domain id to look up. Exactly one of id or name must be set.

### Read-Only

- `click_tracking` (Boolean) Whether click tracking is enabled.
- `created_at` (String) Creation timestamp.
- `open_tracking` (Boolean) Whether open tracking is enabled.
- `records` (Attributes List) DNS records Resend requires for this domain, including inbound MX records when receiving is enabled. Same shape as resend_domain.records. (see [below for nested schema](#nestedatt--records))
- `region` (String) Region the domain is hosted in.
- `status` (String) Domain status: pending, verified, partially_verified, not_started or failed.
- `tracking_subdomain` (String) Subdomain used for open tracking links.
