# resend_api_key

Manages a Resend API key.

## Example Usage

```terraform
resource "resend_domain" "inbound" {
  name = "mail.appcompany.com"

  capabilities = {
    receiving = "enabled"
  }
}

# A key that can only send email via the domain above.
resource "resend_api_key" "ci" {
  name       = "github-actions"
  permission = "sending_access"
  domain_id  = resend_domain.inbound.id
}

output "resend_api_key_token" {
  value     = resend_api_key.ci.token
  sensitive = true
}
```

## Schema

### Required

- `name` (String) API key name.

### Optional

- `domain_id` (String) Resend domain id scoping a sending_access key to a single domain. Changing it creates a new key (and token).
- `permission` (String) Access level: full_access (default) or sending_access. Changing it creates a new key (and token).

### Read-Only

- `created_at` (String) Creation timestamp.
- `id` (String) Resend API key id.
- `last_used_at` (String) Timestamp of the last request made with this key, if any.
- `token` (String, Sensitive) API key token (re_...). Only returned when the key is created; never shown again afterwards.



## Import

Import is supported using the following syntax:

```shell
terraform import resend_api_key.ci <api-key-id>
```

The token cannot be recovered on import (Resend never returns it again), and `permission` is not returned by the API either; both stay null until the key is recreated.
