# resend_domain

Registers a domain with Resend.

## Example Usage

```terraform
# Register automated.appcompany.com with sending + receiving (inbound) enabled.
resource "resend_domain" "inbound" {
  name = "automated.appcompany.com"

  capabilities = {
    sending   = "enabled"
    receiving = "enabled" # Resend serves MX records for inbound email
  }
}

# Publish the DNS records Resend requires (DKIM/SPF for sending, MX for
# receiving). Example with the Cloudflare provider:
#
# resource "cloudflare_record" "resend" {
#   for_each = {
#     for rec in resend_domain.inbound.records :
#     "${rec.record}-${rec.type}-${replace(rec.name, "*", "wild")}" => rec
#   }
#
#   zone_id = var.cloudflare_zone_id
#   type    = each.value.type
#   name    = each.value.name
#   value   = each.value.value
#   ttl     = 1 # Auto
#   priority = each.value.type == "MX" ? each.value.priority : null
#   allow_overwrite = true
# }

# Once the DNS records exist, verify the domain:
#
# resource "resend_domain_verification" "inbound" {
#   domain_id = resend_domain.inbound.id
#   depends_on = [cloudflare_record.resend]
# }
```

## Schema

### Required

- `name` (String) Domain name, e.g. automated.appcompany.com.

### Optional

- `capabilities` (Attributes) Sending/receiving capabilities. Changing capabilities requires replacement. (see [below for nested schema](#nestedatt--capabilities))
- `click_tracking` (Boolean) Track link clicks (requires tracking_subdomain).
- `custom_return_path` (String) Subdomain for the Return-Path address used for SPF alignment and bounce handling. Defaults to send on Resend's side. Changing this replaces the domain.
- `open_tracking` (Boolean) Track email opens (requires tracking_subdomain).
- `region` (String) Region emails are sent from. One of us-east-1, eu-west-1, sa-east-1, ap-northeast-1. Defaults to us-east-1.
- `tls` (String) TLS policy for outbound mail: opportunistic or enforced. Applied via an update after creation.
- `tracking_subdomain` (String) Custom subdomain for open/click tracking (produces a CNAME record). Empty when unset.

### Read-Only

- `created_at` (String) Creation timestamp.
- `id` (String) Resend domain UUID.
- `records` (Attributes List) DNS records Resend requires for this domain, including inbound MX records when receiving is enabled. Create these in your DNS provider. (see [below for nested schema](#nestedatt--records))
- `status` (String) Domain status: not_started, pending, verified, partially_verified, failed, partially_failed.

Optional:
