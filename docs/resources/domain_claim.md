# resend_domain_claim

Starts a domain claim.

## Example Usage

```terraform
resource "resend_domain_claim" "takeover" {
  name = "automated.appcompany.com"
}

# Publish the claim's TXT record in the claimed domain's DNS. Example with
# the Cloudflare provider:
#
# resource "cloudflare_record" "claim_txt" {
#   zone_id = var.cloudflare_zone_id
#   name    = resend_domain_claim.takeover.record.name
#   type    = resend_domain_claim.takeover.record.type
#   value   = resend_domain_claim.takeover.record.value
#   ttl     = 1 # Auto
# }
#
# Then verify with resend_domain_claim_verification, pointing depends_on at
# the DNS record so it exists before verification runs.
```

## Schema

### Required

- `name` (String) Domain to claim.

### Optional

- `click_tracking` (Boolean) Enable click tracking.
- `custom_return_path` (String) Custom subdomain for the bounce return path.
- `open_tracking` (Boolean) Enable open tracking.
- `region` (String) Region to host the domain in once the claim completes.
- `tracking_subdomain` (String) Subdomain used for tracking links.

### Read-Only

- `blocked_reason` (String) Why the claim is blocked (e.g. grace_period), when applicable.
- `domain_id` (String) Placeholder domain id the claim created; also the id resend_domain_claim_verification references.
- `expires_at` (String) When the claim expires if it is not verified.
- `failure_reason` (String) Why the claim failed, when applicable.
- `id` (String) Resend claim id.
- `record` (Attributes) TXT record proving ownership of the claim. Publish it in the claimed domain's DNS, then run resend_domain_claim_verification. (see [below for nested schema](#nestedatt--record))
- `status` (String) Claim status: pending, verified, completed, blocked, expired, superseded, canceled or failed. Updated on refresh.

## Lifecycle

1. Create the claim — the computed `record` (TXT) is only known afterwards, which is why this resource does not verify.
2. Publish `record` in the claimed domain's DNS (point your DNS resources at `resend_domain_claim.this.record`).
3. Create a `resend_domain_claim_verification` referencing this resource's `domain_id`.
